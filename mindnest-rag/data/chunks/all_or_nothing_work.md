# 전부 아니면 전무 — 직장/성과 상황

## 왜곡 유형
전부 아니면 전무 (All-or-Nothing Thinking) — 완벽하지 않으면 완전한 실패로 인식. 회색 지대를 보지 못함.

## 상황 카테고리
직장/성과

## 관련 사용자 표현 예시
- "완벽하게 못 하면 하나마나야"
- "한 가지만 틀려도 다 망한 거잖아"
- "팀장이 칭찬을 안 했어, 내 발표는 실패야"
- "기대한 것보다 못 했어, 완전 망한 거야"
- "부분적으로 성공한 건 성공이 아니야"
- "조금이라도 실수하면 다 소용없어"
- "100점이 아니면 0점이나 마찬가지야"
- "중간에 포기했으니까 전부 망한 거지"
- "딱 한 가지만 틀렸는데 다 못 한 것 같아"
- "팀장이 수정 요청했어, 처음부터 다 틀렸다는 거잖아"
- "한 번 잘못하면 지금까지 잘한 것도 다 날아가는 거야"
- "완전히 성공하지 못하면 의미가 없어"
- "중간 결과는 결과가 아니야, 최종이 모든 걸 결정해"
- "회의에서 한 번 말 실수했어, 다 끝났어"
- "거의 다 됐는데 마지막에 틀렸어, 아예 못 한 것과 같아"
- "기대한 것보다 조금만 못해도 전부 실패야"
- "완벽하게 준비하지 못했으면 시작을 안 했어야 했나봐"
- "절반만 성공한 건 실패랑 다를 게 없어"
- "이 정도면 안 한 거랑 같은 거야"
- "아쉬운 부분이 있으면 다 망한 거야"

## 핵심 패턴
성과를 완벽한 성공 또는 완전한 실패 둘 중 하나로만 판단. 80% 잘해도 20% 부족함만 봄.

## 반례 접근법
- 0%와 100% 사이 어느 지점에 있는지 수치로 생각해보기
- 잘 된 부분과 부족한 부분을 분리해서 목록 작성
- "완벽하지 않음"과 "실패"는 다름
- 타인의 비슷한 성과를 어떻게 평가할지 비교
