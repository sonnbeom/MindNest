# 지나친 일반화 — 직장/성과 상황

## 왜곡 유형
지나친 일반화 (Overgeneralization) — 특정 실패나 결점을 자아 전체 또는 미래 전체로 확대.

## 상황 카테고리
직장/성과

## 관련 사용자 표현 예시
- "나는 항상 이런 실수를 해"
- "나는 어차피 이 일을 잘 못해"
- "이번에도 안 됐어, 나는 절대 안 되는 것 같아"
- "항상 내 의견은 무시당해"
- "나는 뭘 해도 안 돼"

## 핵심 패턴
"이번에 실패했다" → "나는 항상 실패한다"로 과거의 패턴을 미래 전체로 확대.
"항상", "절대", "아무것도" 같은 극단적 단어가 단서.

## 반례 접근법
- "항상"이 정말 맞는지 — 예외가 있었던 상황 탐색
- 이번 실패의 구체적 원인이 다음에도 동일하게 적용되는지 검토
- 과거에 성공했던 경험 하나라도 찾기
- "이번에는" vs "항상"으로 언어 교정
