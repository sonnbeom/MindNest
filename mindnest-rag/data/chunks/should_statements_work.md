# 해야 한다는 생각 — 직장/성과 상황

## 왜곡 유형
해야 한다는 생각 (Should Statements) — 자신이나 타인에게 경직된 기준을 부과하고 그것을 못 지키면 죄의식이나 분노를 느낌.

## 상황 카테고리
직장/성과

## 관련 사용자 표현 예시
- "이 정도는 당연히 잘해야 하는 거잖아"
- "나는 항상 완벽하게 준비해야 해"
- "이것도 못 하면 안 되는데"
- "팀장은 피드백을 더 잘 줬어야 해"
- "나는 실수하면 안 돼"

## 핵심 패턴
"~해야 한다", "~하면 안 된다"는 경직된 규칙으로 자신 또는 타인을 평가.
자신에게 향하면 죄의식과 열등감, 타인에게 향하면 분노와 답답함이 생김.

## 반례 접근법
- "해야 한다"를 "하면 좋겠다"로 바꿔보기 (압박감 감소)
- 이 기준이 어디서 온 것인지 탐색 (타인의 기대? 사회적 규범?)
- 이 기준을 친구에게도 동일하게 적용할지 생각
- 완벽하지 않아도 충분히 좋은 수행의 기준 재설정
