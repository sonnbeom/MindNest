# Before / After 비교 예시

> 생성일: 2026-05-16 09:35  
> RAG 적용 전/후 동일 입력에 대한 LLM 응답 품질 비교  
> 측정 기준: counter_hints 구체성 / fact 정확도 / interpretation 정확도

---

## 비교 기준

| 항목 | Before (RAG 없음) | After (RAG 적용) |
|------|-------------------|-----------------|
| 인지 왜곡 인식 | 일반적인 부정적 사고로 처리 | 특정 왜곡 유형에 맞는 분석 |
| counter_hints | 막연한 반례 | 해당 왜곡·상황에 특화된 반례 |
| 재구성 문장 | 일반적인 위로성 문장 | 왜곡 유형 맞춤 CBT 재구성 |

## case_01 — 직장/성과 — 낙인 찍기

**입력:**
> 오늘 발표에서 말이 꼬였어. 나는 역시 안 되는 사람이야. 이런 것도 제대로 못 하다니.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나는 역시 안 되는 사람이다",
    "나는 이런 것도 제대로 못한다"
  ],
  "fact": "오늘 발표에서 말이 꼬였다",
  "interpretation": "한 번의 실수를 전체 능력 부정으로 해석함",
  "counter_hints": [
    "발표를 준비하고 실행한 노력",
    "과거에 잘했던 경험들",
    "말이 꼬친 것은 준비 부족 vs 능력 문제"
  ],
  "current_actions": [
    "발표를 준비하고 실행함",
    "자신의 실수를 인식하고 반성함"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 발표를 망친 사람이다",
    "나는 역시 안 되는 사람이다"
  ],
  "fact": "오늘 발표 중 말이 꼬였다",
  "interpretation": "한 번의 실수로 자신이 전체적으로 안 되는 사람이라고 결론 내림",
  "counter_hints": [
    "발표 외 잘한 부분의 존재",
    "말 꼬임이 일시적 상황일 가능성",
    "타인도 같은 실수를 하는 보편성"
  ],
  "current_actions": [
    "발표에 도전한 것",
    "실수를 인식하고 돌아봄"
  ]
}
```

**차이점:**

- **counter_hints Before:** 발표를 준비하고 실행한 노력 / 과거에 잘했던 경험들 / 말이 꼬친 것은 준비 부족 vs 능력 문제
- **counter_hints After:**  발표 외 잘한 부분의 존재 / 말 꼬임이 일시적 상황일 가능성 / 타인도 같은 실수를 하는 보편성
- **fact Before:** 오늘 발표에서 말이 꼬였다
- **fact After:**  오늘 발표 중 말이 꼬였다

## case_02 — 직장/성과 — 흑백논리

**입력:**
> 보고서 한 군데 틀렸어. 완벽하게 못 하면 하나마나지. 팀장한테 칭찬도 못 받았고.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나는 완벽하지 못해서 쓸모없다",
    "나는 팀장에게 인정받지 못했다"
  ],
  "fact": "보고서에 오류가 1개 있었고, 팀장으로부터 칭찬을 받지 않았다",
  "interpretation": "1개의 오류 = 완벽함 실패 = 전체 가치 부정, 칭찬 부재 = 무능함의 증거",
  "counter_hints": [
    "대부분의 보고서는 완성되었음",
    "오류 발견 = 검토 과정의 작동",
    "칭찬 없음 ≠ 부정 평가"
  ],
  "current_actions": [
    "보고서 작성 완료",
    "오류 확인 및 인식"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 실패한 것 같다",
    "나는 완벽하지 못한 사람이다"
  ],
  "fact": "보고서에 오류가 한 곳 있었고, 팀장의 칭찬이 없었다",
  "interpretation": "한 곳의 오류가 전체 보고서를 무의미하게 만든다",
  "counter_hints": [
    "한 곳 외 나머지는 완성된 보고서",
    "칭찬 부재가 부정 평가는 아님",
    "오류 발견 자체가 검토 능력"
  ],
  "current_actions": [
    "보고서 완성 및 제출",
    "스스로 오류 인지"
  ]
}
```

**차이점:**

- **counter_hints Before:** 대부분의 보고서는 완성되었음 / 오류 발견 = 검토 과정의 작동 / 칭찬 없음 ≠ 부정 평가
- **counter_hints After:**  한 곳 외 나머지는 완성된 보고서 / 칭찬 부재가 부정 평가는 아님 / 오류 발견 자체가 검토 능력
- **fact Before:** 보고서에 오류가 1개 있었고, 팀장으로부터 칭찬을 받지 않았다
- **fact After:**  보고서에 오류가 한 곳 있었고, 팀장의 칭찬이 없었다

## case_03 — 직장/성과 — 성급한 결론

**입력:**
> 팀장이 오늘 내 의견을 또 무시했어. 어차피 내가 뭘 말해도 달라지는 게 없을 거야.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나는 팀장에게 무시당하는 것 같다",
    "나는 말해도 소용없을 것 같다"
  ],
  "fact": "팀장이 오늘 당신의 의견에 응하지 않았다",
  "interpretation": "그 상황을 앞으로도 반복될 것으로 일반화했다",
  "counter_hints": [
    "이전에 의견이 받아들여진 적 있음",
    "한 번의 상황으로 전체를 판단한 것",
    "팀장의 그날의 상황이나 우선순위 미파악"
  ],
  "current_actions": [
    "의견 표현 시도 지속",
    "상황을 인식하고 분석하려는 노력"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 무시당하는 존재인 것 같다",
    "나는 어떤 말도 소용없을 것 같다"
  ],
  "fact": "팀장이 오늘 내 의견을 채택하지 않았다",
  "interpretation": "앞으로도 영원히 내 의견은 받아들여지지 않을 것이다",
  "counter_hints": [
    "의견 채택 여부와 존중은 별개",
    "상황적 이유가 있을 가능성",
    "다른 방식으로 전달할 여지"
  ],
  "current_actions": [
    "의견을 적극적으로 표현함",
    "상황을 인식하고 돌아봄"
  ]
}
```

**차이점:**

- **counter_hints Before:** 이전에 의견이 받아들여진 적 있음 / 한 번의 상황으로 전체를 판단한 것 / 팀장의 그날의 상황이나 우선순위 미파악
- **counter_hints After:**  의견 채택 여부와 존중은 별개 / 상황적 이유가 있을 가능성 / 다른 방식으로 전달할 여지
- **fact Before:** 팀장이 오늘 당신의 의견에 응하지 않았다
- **fact After:**  팀장이 오늘 내 의견을 채택하지 않았다

## case_04 — 인간관계 — 낙인 찍기

**입력:**
> 친구가 연락을 안 해. 나는 원래 매력 없는 사람이라서 그런 것 같아. 항상 내가 먼저 연락해야 해.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나는 매력 없는 사람이다",
    "나는 항상 먼저 연락해야 한다"
  ],
  "fact": "친구가 최근 연락하지 않았다",
  "interpretation": "친구의 침묵을 자신의 매력 부족으로 해석함",
  "counter_hints": [
    "친구의 바쁜 일정이나 상황 변화",
    "관계마다 다른 연락 패턴의 정상성",
    "과거 친구가 응한 긍정적 반응들"
  ],
  "current_actions": [
    "친구와의 관계 유지 시도",
    "연락을 통한 관계 관심 표현"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 매력 없는 사람이다",
    "나는 항상 먼저 연락해야 한다"
  ],
  "fact": "친구가 먼저 연락하지 않고 있다",
  "interpretation": "이것이 내 매력 없음을 증명한다고 판단함",
  "counter_hints": [
    "친구의 바쁜 상황 가능성",
    "연락 스타일의 차이",
    "관계의 다양한 역할 분담"
  ],
  "current_actions": [
    "관계 유지를 위한 노력",
    "자신의 감정 인식"
  ]
}
```

**차이점:**

- **counter_hints Before:** 친구의 바쁜 일정이나 상황 변화 / 관계마다 다른 연락 패턴의 정상성 / 과거 친구가 응한 긍정적 반응들
- **counter_hints After:**  친구의 바쁜 상황 가능성 / 연락 스타일의 차이 / 관계의 다양한 역할 분담
- **fact Before:** 친구가 최근 연락하지 않았다
- **fact After:**  친구가 먼저 연락하지 않고 있다

## case_05 — 인간관계 — 지나친 일반화

**입력:**
> 소개팅에서 또 거절당했어. 나는 사람들한테 항상 별로인가봐. 이번이 세 번째야.

```json
{
  "thoughts": [

  ],
  "fact": "소개팅에서 3번 거절당했다",
  "interpretation": "거절 경험을 자신의 전반적 가치로 일반화함",
  "counter_hints": [

    "소개팅 외 다른 관계에서의 평가"
  ],
  "current_actions": [
    "새로운 만남을 시도하고 있음",

  ]
}
```

**After (RAG 적용):**

```json
  "fact": "소개팅에서 세 번 거절을 경험했다",

    "감정을 언어로 표현하는 중"
  ]
}
```

**차이점:**

- **counter_hints Before:** 한 번의 만남으로 전부를 판단하기 어려움 / 상대의 개인적 사정이나 선호도 영향 / 소개팅 외 다른 관계에서의 평가
- **counter_hints After:**  소개팅 궁합의 다양한 변수 / 상대방의 개인적 기준 차이 / 세 번은 전체 샘플이 아님
- **fact Before:** 소개팅에서 3번 거절당했다
- **fact After:**  소개팅에서 세 번 거절을 경험했다

```json
    "기술적 오류로 메시지를 못 본 경우",
    "답장 의도는 있지만 시간이 필요한 상황"
  ],
  "current_actions": [
    "상대와 소통하려는 시도",

  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [

  ],
  "fact": "카톡 메시지가 읽혔으나 답장이 오지 않았다",

  ]
}
```

**차이점:**

- **counter_hints Before:** 상대방이 바쁜 상태일 수 있음 / 기술적 오류로 메시지를 못 본 경우 / 답장 의도는 있지만 시간이 필요한 상황
- **counter_hints After:**  단순히 바빠서 못 답한 가능성 / 답장 타이밍의 개인 차이 / 메시지 내용과 무관한 상황
- **fact Before:** 카톡 메시지에 아직 답장이 오지 않았다
- **fact After:**  카톡 메시지가 읽혔으나 답장이 오지 않았다

## case_08 — 자존감 — 긍정적인 면 무시하기

**입력:**
> 주변 친구들은 다 잘 되는데 나만 제자리야. 내가 칭찬받아도 그냥 운이 좋았던 거지 실력이 아니야.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나만 제자리에 있는 것 같다",
    "나는 실력이 없는 것 같다"
  ],
  "fact": "주변 친구들의 성과와 자신의 성과가 다르다",
  "interpretation": "자신의 성과는 운이고 친구들의 성과는 실력이라고 판단함",
  "counter_hints": [
    "칭찬받은 구체적 상황 재검토",
    "친구들의 어려움이나 실패 경험",
    "운과 실력의 정의 재고찰"
  ],
  "current_actions": [
    "친구들의 성장 관찰하기",
    "자신의 성과에 대한 피드백 수용하기"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 혼자 뒤처지고 있다",
    "나는 실력이 없는 것 같다"
  ],
  "fact": "친구들의 근황을 들었고, 최근 칭찬을 받은 일이 있었다",
  "interpretation": "나만 정체되어 있고, 칭찬은 실력이 아닌 운 덕분이다",
  "counter_hints": [
    "성장 속도의 개인차 존재",
    "칭찬을 받을 행동의 반복성",
    "운과 실력의 복합적 작용"
  ],
  "current_actions": [
    "자신의 상태를 직면하기",
    "칭찬받을 행동 지속하기"
  ]
}
```

**차이점:**

- **counter_hints Before:** 칭찬받은 구체적 상황 재검토 / 친구들의 어려움이나 실패 경험 / 운과 실력의 정의 재고찰
- **counter_hints After:**  성장 속도의 개인차 존재 / 칭찬을 받을 행동의 반복성 / 운과 실력의 복합적 작용
- **fact Before:** 주변 친구들의 성과와 자신의 성과가 다르다
- **fact After:**  친구들의 근황을 들었고, 최근 칭찬을 받은 일이 있었다

## case_09 — 자존감 — 흑백논리

**입력:**
> 목표했던 자격증 시험에서 1점 차이로 떨어졌어. 이 정도도 못 하면 나는 뭘 해도 안 되는 사람이야.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나는 1점 차이로 떨어져 능력이 없는 것 같다",
    "나는 뭘 해도 안 되는 사람이다"
  ],
  "fact": "목표한 자격증 시험에서 1점 차이로 합격하지 못했다",
  "interpretation": "1점 차이라는 작은 격차를 자신의 전반적 능력 부족으로 해석",
  "counter_hints": [
    "1점은 운, 컨디션 차이일 수 있음",
    "과거 성공 경험들의 존재",
    "재응시 기회와 개선 가능성"
  ],
  "current_actions": [
    "자격증 취득을 위해 시험 준비함",
    "실패 상황을 직시하고 반성함"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 뭘 해도 안 되는 사람이다",
    "나는 이 정도도 못 하는 사람이다"
  ],
  "fact": "자격증 시험에서 1점 차이로 불합격했다",
  "interpretation": "1점 차이 불합격이 전체 능력의 실패를 의미한다",
  "counter_hints": [
    "1점 차이는 합격 근접 증거",
    "재도전 시 합격 가능성",
    "시험 준비 과정의 실력 축적"
  ],
  "current_actions": [
    "자격증 취득 도전",
    "목표 설정과 실행"
  ]
}
```

**차이점:**

- **counter_hints Before:** 1점은 운, 컨디션 차이일 수 있음 / 과거 성공 경험들의 존재 / 재응시 기회와 개선 가능성
- **counter_hints After:**  1점 차이는 합격 근접 증거 / 재도전 시 합격 가능성 / 시험 준비 과정의 실력 축적
- **fact Before:** 목표한 자격증 시험에서 1점 차이로 합격하지 못했다
- **fact After:**  자격증 시험에서 1점 차이로 불합격했다

## case_10 — 자기 비난 — 가족

**입력:**
> 엄마랑 또 싸웠어. 내가 너무 예민하게 반응한 것 같아. 항상 내가 문제야.

**Before (RAG 없음):**
```json
{
  "thoughts": [
    "나는 너무 예민한 것 같다",
    "나는 항상 문제다"
  ],
  "fact": "엄마와 싸움이 발생했다",
  "interpretation": "자신의 예민함이 싸움의 원인이라고 판단함",
  "counter_hints": [
    "싸움에는 양쪽의 상황이 작용함",
    "예민함이 항상 부정적인 것만은 아님",
    "구체적 상황 검토 필요"
  ],
  "current_actions": [
    "싸움 후 자신의 반응 돌아보기",
    "책임을 인식하고 성찰하기"
  ]
}
```

**After (RAG 적용):**
```json
{
  "thoughts": [
    "나는 항상 문제인 것 같다",
    "나는 너무 예민한 것 같다"
  ],
  "fact": "엄마와 다툼이 있었다",
  "interpretation": "다툼의 원인이 전적으로 나의 예민함 때문이다",
  "counter_hints": [
    "갈등은 양방향 상호작용",
    "예민함이 항상 나쁜 것은 아님",
    "한 번의 다툼이 전부가 아님"
  ],
  "current_actions": [
    "자신의 반응 돌아보기",
    "감정을 언어로 표현하기"
  ]
}
```

**차이점:**

- **counter_hints Before:** 싸움에는 양쪽의 상황이 작용함 / 예민함이 항상 부정적인 것만은 아님 / 구체적 상황 검토 필요
- **counter_hints After:**  갈등은 양방향 상호작용 / 예민함이 항상 나쁜 것은 아님 / 한 번의 다툼이 전부가 아님
- **fact Before:** 엄마와 싸움이 발생했다
- **fact After:**  엄마와 다툼이 있었다
