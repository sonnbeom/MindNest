# Before / After 비교 예시

> RAG 적용 전/후 동일 입력에 대한 LLM 응답 품질 비교  
> 측정 기준: 인지 왜곡 인식 정확도 / counter_hints 구체성 / 재구성 문장 품질

---

## 비교 기준

| 항목 | Before (프롬프트 엔지니어링만) | After (RAG 적용) |
|------|-------------------------------|-----------------|
| 인지 왜곡 인식 | 일반적인 부정적 사고로 처리 | 특정 왜곡 유형 명확히 인식 |
| counter_hints | 막연한 반례 | 해당 왜곡에 특화된 반례 |
| 재구성 문장 | 일반적인 위로성 문장 | 왜곡 유형 맞춤 CBT 재구성 |

---
